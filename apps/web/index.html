Tessera

No server holds the game. Your browsers agree with each other.

At the end, whoever holds the most ground wins. A longer game also opens the door for late joiners longer and waits longer before it calls a silent empire abandoned — one number sets all three, because a three-hour patience in a ten-day game is a losing condition for going to bed.

Empires nobody is playing yet, for people to claim after the game has started — which is how somebody who finds your game on a board gets in. Their ground is kept clear until they arrive.

Watch a saved game

Open a log saved with Save log — yours, or one somebody sent you. Your browser checks every signature in it and replays the whole game to see whether it reaches the state the file claims, so nothing here is taken on anyone’s word.

Settings

Shown as name#fingerprint wherever somebody is deciding something about you, because anybody may pick any name and the fingerprint is what tells two of them apart. Kept in this browser, and said again in every game you join.

Where this browser looks for games other people are running, and where it posts one of yours if you ask it to. Anyone can run a board and anyone can list a game on one, so your browser checks every game it is shown rather than believing the board.

One per line. A host peer serves the log of a game it kept at /room/<room>/archive, and the leaderboard above is built out of whichever of those you list, plus any file you open. There is no index of finished games anywhere, so a table here is over what you have and says so.

A service that starts a room for you and keeps it open while you are asleep, so a long game does not end when you close the tab. It is a doorman and never a referee: the game is still sealed by this browser and checked by everybody in it, so a service that hands back the wrong room is a room that refuses you.
